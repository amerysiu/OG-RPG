# Agent Notes

Main scene is `res://scenes/iso_world.tscn` (2.5D isometric world, 8 zones in a row).

Autoloads: `RoomStateManager` (Summer set_synced/get_synced + ENet fallback), `ZoneCatalog` (zone look + layout), `CCAssetFetcher` (textures, phoneme/word/chunk audio), `Learner` (per-child OG progress, saved to user://og_learner.json), `MainGameManager` (legacy, idle).

## OG system (scripts/og/)
- `og_data.gd` - GENERATED by `tools/curriculum/curriculum.py`. 42 stages, ~650 word entries, sentences, spelling families. Never hand-edit.
- `og_curriculum.gd` (class OGCurriculum) - read-only queries: stage(), sequence(), zone_stages(), words().
- `learner.gd` (autoload Learner) - record(stage, correct), mastery (80% of last 10, N days), adaptive tier, unlocks, bosses, placement, teacher settings.
- `question_factory.gd` (class QuestionFactory) - make({stage, attack, tier, ...}) -> question dict. 25 modes, 6 kinds: build, phoneme, choice, count, split, type.
- `scripts/combat/battle_screen.gd` renders every kind, applies tier levers, records each item via Learner.
- `scripts/ui/progress_panel.gd` - Learning Map + teacher controls (M key / Map button; opens as welcome on first run).

## Zones (ZoneCatalog / curriculum ZONES)
0 Echo Meadow (A1-A7, oral) · 1 Phoneme Village (B1-B6) · 2 Closed-Syllable Woods (C1-C8) · 3 Long-Vowel Lake (D1-D3) · 4 Growling Caves (D4-D7) · 5 Syllable Mountains (E1-E6) · 6 Morpheme Citadel (F1-F4) · 7 Root Ruins (F5-F6). Each zone: one monster per stage (sleeps until unlocked, respawns after 18 s), a boss (cumulative review of the zone, wakes when all zone stages are mastered, opens the next gate), a Rule-breaker (heart words, zones 1+). Daily Quest Board (R1 sentences + review) in Phoneme Village.

## Tests
`godot --headless res://tests/test_runner.tscn` - generates every stage x attack x tier, plays correct and wrong answers through the battle screen, checks mastery / unlock / placement rules and a full world fight. Must report 0 failures.
`tests/dump_questions.tscn` prints one sample question per stage/attack for a content read-through.

Do not extend `SummerGame` unless the class exists in the running engine. RoomStateManager already binds to `Summer` / `set_synced` when present.
